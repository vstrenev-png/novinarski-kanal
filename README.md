# novinarski-kanal

Автоматизиран YouTube/TikTok канал със **сатиричен AI анализ на български новини**.
No-code реализация (Make.com + Claude + TTS + видео генератор).

## Съдържание на repo-то

| Файл | Какво е |
|---|---|
| `README.md` | този файл — обща карта |
| `ai-analizator-persona.md` | **персонажната карта** — system prompt за Claude стъпката |
| `handoff-novinarski-kanal.md` | контекст и взети решения |
| `01-make-scenariy.md` | пълният Make.com сценарий стъпка по стъпка (2 входа + обща втора половина) |
| `02-tts-i-video-instrumenti.md` | сравнение и препоръка за глас (ElevenLabs) и видео (Creatomate/HeyGen), цени 2026 |
| `03-prototip-primeri.md` | 3 реални примера на изхода на Claude стъпката (от новини 25.07.2026) |
| `04-novinarski-blokove.md` | как се коментират и **ТВ новинарските блокове** + правни предпазители |

## Двата входа за новини

1. **RSS** от български сайтове (Actualno, Sega, Dnevnik, Mediapool, БТА) — нисък риск, лесен старт.
2. **ТВ новинарски блокове** — през официалните YouTube канали на телевизиите (БНТ, NOVA, bTV) → транскрипция → теми. По-висок риск, добавя се втори.

И двата се събират в обща верига: **подбор → скрипт (персонажът) → глас → видео → човешки спот-чек → публикуване + AI етикет**.

## Ред на действие

1. Прочети `handoff-...` и `ai-analizator-persona.md`.
2. Виж примерите в `03-prototip-primeri.md` — одобри тона.
3. Избери инструменти по `02-...`.
4. Сглоби Make сценария по `01-...` (първо само RSS входа, докрай).
5. Добави ТВ блоковете по `04-...`.
