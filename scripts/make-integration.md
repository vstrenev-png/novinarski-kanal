# Как се връзват endpoint-ите в Make.com (наръчник за кликане)

> Този файл допълва `01-make-scenariy.md`. Там е целият сценарий; тук е конкретно
> **как Make вика нашите три endpoint-а** (`/generate`, `/transcribe`, `/extract-topics`)
> и как изходът им се подава към ElevenLabs и Creatomate. Без код — само настройки.

## 0. Предварително

- Сървърът трябва да е достъпен от интернет (Make не вижда `localhost`).
  За тест: `npm start` + `npx ngrok http 3000` → получаваш адрес от вида
  `https://нещо.ngrok.app`. По-долу той е наречен `АДРЕС`.
- Всички викания стават с модула **HTTP → Make a request**.

---

## 1. Скриптът на клипа — `POST /generate`

Замества директния „Claude" модул от стъпка „СКРИПТ (персонажът)" в `01-make-scenariy.md`.
Предимството: персонажът, валидацията и повторните опити са вече вградени — Make получава
или чист JSON, или ясна грешка.

Настройки на **HTTP → Make a request** (вътре в Iterator-а, за всяка избрана тема):

| Поле | Стойност |
|---|---|
| URL | `АДРЕС/generate` |
| Method | `POST` |
| Body type | `Raw` |
| Content type | `JSON (application/json)` |
| Request content | `{ "title": "{{title}}", "fact": "{{fact}}" }` |
| Parse response | ✅ Yes |

Какво връща (готови полета, без нужда от отделен „Parse JSON" модул):

```json
{
  "hook": "...",
  "analiz": "...",
  "poanta": "...",
  "hashtags": ["#...", "#...", "#..."]
}
```

Ако след 3 опита изходът пак е невалиден, endpoint-ът връща **статус 422** —
в Make сложи Error handler (Right-click върху модула → Add error handler → напр.
„Ignore" + ред в Google Sheets „за ръчна проверка"), за да не спира целият сценарий.

### 1а. Мапване към ElevenLabs (глас)

В модула **ElevenLabs → Text to Speech**:

- Поле **Text**: кликни в полето и сглоби от изхода на HTTP модула:
  `{{hook}} {{analiz}} {{poanta}}` (с по един интервал между тях).
- Voice: избраният български глас (виж `02-tts-i-video-instrumenti.md`).

### 1б. Мапване към Creatomate (видео + субтитри + хаштагове)

В модула **Creatomate → Render a Video** (с твоя шаблон):

- Полето за **текст на субтитрите**: същото сглобено `{{hook}} {{analiz}} {{poanta}}`
  (или само `{{hook}}`, ако шаблонът ти показва отделно заглавие).
- Полето за **аудио**: URL-ът на mp3 файла от ElevenLabs модула.
- Хаштаговете: в описанието на клипа при публикуване — мапни `{{join(hashtags; " ")}}`
  (функцията `join` слепва масива с интервал: `#жега #Пловдив #климат`).

## 2. ТВ входът, част 1 — `POST /transcribe`

Използва се във „Вход Б", когато емисията няма YouTube субтитри и имаш **аудио URL**.

| Поле | Стойност |
|---|---|
| URL | `АДРЕС/transcribe` |
| Method | `POST` |
| Body type | `Raw` |
| Content type | `JSON (application/json)` |
| Request content | `{ "audioUrl": "{{линкът към аудио файла}}" }` |
| Parse response | ✅ Yes |

Връща: `{ "transcript": "целият текст на емисията..." }`.

⚖️ Помни правилата от `04-novinarski-blokove.md`: работим само с текста за
идентифициране на теми — никакви кадри, лого или глас от емисията в клиповете.

---

## 3. ТВ входът, част 2 — `POST /extract-topics`

Веднага след `/transcribe` (или след модула за YouTube субтитри):

| Поле | Стойност |
|---|---|
| URL | `АДРЕС/extract-topics` |
| Method | `POST` |
| Body type | `Raw` |
| Content type | `JSON (application/json)` |
| Request content | `{ "transcript": "{{transcript от предишния модул}}" }` |
| Parse response | ✅ Yes |

Връща до 8 неутрални теми в **същия формат като RSS входа**:

```json
{ "topics": [ { "title": "...", "fact": "..." }, ... ] }
```

След това: **Iterator** върху `topics` → сливане с темите от Вход А (Array aggregator)
→ Claude „ПОДБОР" → и всяка избрана тема отива към `/generate` (точка 1).

---

## 4. Веригата накратко

```
Вход А (RSS) ──────────────────────────────┐
Вход Б: аудио URL → /transcribe →          ├─► ПОДБОР → за всяка тема: /generate
        /extract-topics → теми ────────────┘                    │
                                                   hook+analiz+poanta → ElevenLabs (глас)
                                                   субтитри+хаштагове → Creatomate (видео)
                                                                 │
                                                        ✋ ЧОВЕШКИ СПОТ-ЧЕК
                                                                 │
                                                     Публикуване + AI етикет
```

## 5. Къде точно е човешкият спот-чек

**След Creatomate (готовото видео) и ПРЕДИ публикуването** — както е описано в
`01-make-scenariy.md`:

1. Модул „Google Sheets → Add a row" (или „Telegram Bot → Send a message" с бутони):
   записва заглавие, пълния текст (`hook`+`analiz`+`poanta`), линк към видеото, статус „за преглед".
2. Ти преглеждаш (~5 мин/ден) и маркираш „ок".
3. Router пуска към публикуване само редовете със статус „ок".

Това е застраховката срещу тонов гаф или правен риск, преди клипът да излезе —
особено важно за клиповете от ТВ входа.
