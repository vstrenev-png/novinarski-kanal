## 4. ВТОРА ЗАДАЧА — къде Claude Code реално помага

Make сценарият се сглобява от собственика (no-code, с кликане). Claude Code добавя стойност в „лепилото" около него. По приоритет:

1. **Deepgram транскрипция helper** (за ТВ входа) — малък скрипт/HTTP пример: подаваш URL/аудио → връща текст. Виж `04-novinarski-blokove.md`. Може да е edge function или прост Node/Python скрипт, който Make вика през webhook.
2. **Claude „скрипт" повикване** — готов пример за HTTP заявка към Claude API с persona system prompt-а от `ai-analizator-persona.md` и user = `Заглавие + Факт`, който връща строгия JSON. Тествай, че JSON-ът винаги е валиден (виж схемата в `03-...`).
3. **JSON schema валидатор** — малка проверка, че изходът има точно `hook, analiz, poanta, hashtags`, преди да тръгне към TTS. Ако не е валиден → retry.
4. (Опционално) **Make blueprint** — ако решите, можеш да генерираш скеле на Make сценарий като JSON blueprint за импорт.

Не пипай тона/правилата на персонажа — те са бизнес решение, не техническо.

## 5. Твърди правила (важат за всеки генериран текст/пример)

От `ai-analizator-persona.md`, накратко:
- Без псувни, без обиди по признаци, без сексуално/вулгарно.
- Без имена на реални предавания, водещи, рубрики, лога.
- Само **заглавие + кратък факт + оригинален коментар** — никакъв преразказ или дълги цитати.
- Без измислени факти.
- Спорни теми — подиграй абсурда от всички страни, без партийна позиция.
- Изход строго в JSON: `{hook, analiz, poanta, hashtags}`.

## 6. Правна рамка (пази монетизацията)

- Пресни новини = сродни права на издателите (ЗАПСП, Директива ЕС 2019/790). Работим само със заглавие+факт+оригинален коментар.
- ТВ блокове: нула техни кадри/лого/глас в клиповете; входът е само сигнал за теми през официалните YouTube канали (БНТ, NOVA, bTV). Подробно в `04-...`.
- Задължителен видим „AI-generated" етикет при публикуване.
- Това са практически насоки, не правен съвет.
