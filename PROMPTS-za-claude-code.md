## Prompt 2 — Генераторът на скрипт (сърцето): Заглавие+Факт → валиден JSON

```
Направи HTTP endpoint, който Make ще вика през webhook, за да генерира текста на един клип.

Изисквания:
- Endpoint: POST /generate, тяло: { "title": "...", "fact": "..." }
- Използвай официалния Anthropic SDK. За модел избери актуален Claude модел от Messages API (провери в документацията на Anthropic кой е текущият препоръчан модел — не слагай остаряло име).
- System prompt = ЦЕЛИЯТ текст от файла `ai-analizator-persona.md` (частта между --- линиите). Чети го от файла по време на изпълнение, не го копирай ръчно, за да остане един източник на истината.
- User съобщение: "Заглавие: {title}\nФакт: {fact}"
- Отговор: строго JSON със схема { hook: string, analiz: string, poanta: string, hashtags: string[] }.
- ВАЖНО: изходът трябва да е ВАЛИДЕН JSON винаги. Ако Claude върне нещо, което не се парсва или не отговаря на схемата — направи retry до 3 пъти. Ако и след 3-те пъти е невалиден — върни HTTP 422 с ясна грешка.
- Валидация на схемата: hook/analiz/poanta са непразни стрингове; hashtags е масив от 3 до 5 непразни стринга. Изнеси валидацията в отделен модул `scripts/validate.js`, за да се преизползва.
- Логвай накратко всяка заявка (title + дали е минала от първи опит).

След като го напишеш: пусни го локално и ми покажи, че работи, като го тестваш с този вход:
{ "title": "Асфалтът в Пловдив достигна 67°C при екстремна жега", "fact": "Измерена температура на асфалта 67 градуса по време на гореща вълна." }

Обясни ми на български как да задам ANTHROPIC_API_KEY и как Make ще вика този endpoint.
```

- За всяка извикай логиката на /generate и провери, че резултатът минава валидацията от `scripts/validate.js` (валиден JSON, правилна схема, 3–5 хаштага).
- Тестът да пада ясно, ако някой изход е невалиден.
- Добави npm script `npm test`.

Пусни `npm test` и ми покажи резултата. Обясни на български какво тества.
```

## Prompt 4 — Транскрипция на ТВ емисиите (вход Б)

```
Прочети `04-novinarski-blokove.md` за контекст. Направи втори endpoint за ТВ входа.

Част 1 — транскрипция:
- Endpoint: POST /transcribe, тяло: { "audioUrl": "..." } (линк към аудио файл).
- Използвай Deepgram (DEEPGRAM_API_KEY от .env). Задай език български. Върни само чистия текст (транскрипт).

Част 2 — извличане на теми:
- Endpoint: POST /extract-topics, тяло: { "transcript": "..." }
- Извикай Claude (същия модел като в Prompt 2) с инструкция: „Извади до 8 отделни новинарски теми от този транскрипт. За всяка върни кратко НЕУТРАЛНО заглавие (без сатира) + едно изречение факт. Без цитати, без преразказ." Върни строг JSON: масив от { title, fact }.
- Валидирай, че всеки елемент има непразни title и fact; retry до 3 пъти при невалиден JSON.

Спазвай правните бележки от `04-novinarski-blokove.md`: работим само с текст/теми, никакви кадри или глас от емисията. Не сваляй видео — работи само с подадено аудио URL.

Пусни локално, обясни ми на български как да задам DEEPGRAM_API_KEY и как двата endpoint-а се връзват в Make (transcribe → extract-topics → нататък към /generate).
```

## Правила, които важат за всеки prompt

Тези идват от `ai-analizator-persona.md` и `04-novinarski-blokove.md` — Claude Code трябва да ги пази във всеки генериран текст/пример:
- Изход строго JSON: `{hook, analiz, poanta, hashtags}`.
- Без псувни, без обиди по признаци, без имена на реални предавания/водещи.
- Само заглавие + факт + оригинален коментар; без преразказ или дълги цитати; без измислени факти.
- Спорни теми — без партийна позиция.
- ТВ вход — нула техни кадри/лого/глас.
