# Прототип на Claude стъпката — реални примери

> Взех **реални заглавия от 25 юли 2026 г.** (Сега, Dnes.bg) и ги прекарах през персонажа.
> Целта е да видиш крайния текст на клипа, преди да строим техниката.
> Всеки изход е **строго в JSON формата** от персонажната карта — точно това, което ще излиза от AI стъпката в Make.
>
> ⚠️ Забележка: коментарът е 100% оригинален. Работено е само със **заглавие + кратък факт**, без преразказ на статии. Не са добавяни факти извън подаденото.

## Как се чете това за видеото

Пълният **текст за озвучаване (TTS)** се сглобява така:

```
{hook}  →  {analiz}  →  {poanta}
```

Тоест за Пример 1 гласът чете:
> „Асфалтът в Пловдив стигна 67 градуса. Вече не се шофира по улиците — там се пекат кюфтета. 67 градуса, батка… (и т.н.) … Климатът се сменя по-бързо от реакцията ни."

- **hook** = първите 2 секунди (задържа зрителя да не превърти)
- **analiz** = тялото на клипа (реалната аналитична стойност — това пази монетизацията)
- **poanta** = завършек (подканва коментар/споделяне)
- **hashtags** = отиват в описанието на YouTube/TikTok

Средна дължина: ~40–55 секунди говор → идеално за Shorts/TikTok.

## Проверка спрямо правилата на персонажа

| Правило | Спазено? |
|---|---|
| Без псувни/вулгарности | ✅ |
| Без имена на реални предавания/водещи | ✅ |
| Без обиди по признаци | ✅ |
| Само заглавие + факт, без преразказ | ✅ |
| Без измислени факти | ✅ |
| Спорни теми — подигравка на абсурда от всички страни | ✅ (Пример 3 не заема партия) |
| Лека самоирония „AI" | ✅ (и в трите) |

Ако одобриш тона на тези три — точно това ще генерира стъпка 5 от сценария, автоматично, всеки ден.
